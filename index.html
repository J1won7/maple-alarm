메이플 화면 알리미

선택한 게임 화면에서 설치기 이미지를 감지한 뒤 지정한 시간 후 알립니다. 모든 화면 분석은 이 브라우저 안에서 수행됩니다.

기존 설치기 감지

전체 화면을 검사합니다.

감지 후 40초 뒤 타이머 알림

기준 이미지와 OpenCV를 준비하고 있습니다.
현재 유사도--
기록 최고 유사도--
권장 정확도--
감지 간격0.5초
--알림 대기 없음

사용 방법

1. 게임의 해상도와 창/전체 화면 상태를 선택합니다.

2. 화면 공유를 누르고 게임 창 또는 모니터를 선택합니다.

3. 처음에는 정확도 99%로 한 사이클을 확인해 최고 유사도를 기록합니다.

4. 권장 정확도를 적용한 뒤 감지를 시작합니다. 일반값은 감지 시점인 50초 기준으로 계산됩니다.

기본 알림음은 띠링.mp3, 추가 반복 알림음은 물음표.mp3를 사용합니다.
